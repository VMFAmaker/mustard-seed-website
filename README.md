# Mustard Seed website

Next.js 16 site for Mustard Seed Ltd (Counselling & Business Incubator).

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Where things live

- `lib/site.ts`: company details (email, phone, address, company number), pillars, journey, values, documents list. **Fill in the `null` details here.**
- `app/`: one folder per page (`/about`, `/how-it-works`, `/services`, `/services/[slug]`, `/contact`, `/documents`, `/documents/[slug]`)
- `app/globals.css`: all styling (brand colours at the top)
- `components/Roots.tsx`: the animated sprout-and-roots illustration (shape generated by `scripts/generate-roots.py`)
- `content/documents/`: policies converted from the Word files in *Mustard Seed Official* by `scripts/convert-docs.py`. Re-run it after editing a document or filling in its details.

## Contact form

Without an email service, the form prepares the visitor's message for them to send from their own email app. To receive enquiries directly, create a free [Resend](https://resend.com) account, verify your domain, and set these environment variables where the site is hosted:

- `RESEND_API_KEY`
- `CONTACT_FROM`, e.g. `Mustard Seed <website@yourdomain.co.uk>`
- `CONTACT_TO` (optional, defaults to the email in `lib/site.ts`)

## Put it online

Deploy to [Vercel](https://vercel.com) (free tier): import this folder or run `npx vercel`, then connect your domain.
